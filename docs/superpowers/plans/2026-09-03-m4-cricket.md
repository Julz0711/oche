# M4: Cricket Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Cricket (Standard variant) as the app's second `GameModule`, proving the existing interface genuinely generalizes beyond X01 — with zero changes to any M3 remote-play route.

**Architecture:** First, fix a design smell M3's final review introduced (X01-only scoring math leaking into supposedly generic UI/route code) by making every engine derive its own score from `sector`+`ring`+`state`, never trusting an incoming `Throw.points`. Then build Cricket's engine/UI/stats mirroring X01's file layout exactly, and wire it into the registry.

**Tech Stack:** TypeScript (strict), Vitest, React/Tailwind (existing conventions), Zod.

**Spec:** [docs/superpowers/specs/2026-09-03-m4-cricket-design.md](../specs/2026-09-03-m4-cricket-design.md) (read this too — full rationale for every decision this plan implements).

## Global Constraints

- No `GameModule` interface signature changes (`lib/types.ts` is not touched by this plan at all).
- Every engine's `applyThrow(state, throw_, settings)` must derive the real score from `throw_.sector`/`throw_.ring` (and, for Cricket, its own `state`) — never read `throw_.points` as authoritative input.
- No changes to any M3 route (`app/api/matches/**`), `lib/matchThrows.ts`, `lib/matchLobby.ts`, `lib/identity.ts`, `lib/realtime.ts`, `store/match.ts`, or `hooks/useRemoteMatchSync.ts`. If implementation reveals one of these genuinely needs a change, stop and flag it as a spec defect — do not silently patch around it.
- Cricket's file layout, testing rigor, and code conventions mirror `lib/games/x01/`'s exactly (same file names, same accessor-wiring shape in `index.ts`, same "Before" snapshot pattern in `VisitHistoryEntry` for `undo`).
- Cricket numbers in play are fixed: 20, 19, 18, 17, 16, 15, Bull. Not configurable.
- `CricketSettings` has exactly one field: `firstTo` (legs). No starting score, no check-in/check-out variants.
- Test suite must stay green throughout. Starting count: 77 (68 from M3 + 9 in `lib/scoring.test.ts`, which Task 2 deletes).

- [ ] **Step 2: Add the internal points-deriving function**

Add this new private function immediately after `computeVisitTotal` (which stays exported and unchanged):

```ts
/** Derives a dart's real point value from its sector+ring — the single source of truth for X01
 *  scoring. Never trust an incoming Throw's `points` field; always recompute it here, so a
 *  forged value (e.g. from a malicious API client) has no effect on the resulting score. */
function computeDartPoints(sector: Throw['sector'], ring: Throw['ring']): number {
  if (ring === 'M') return 0;
  if (ring === 'OB') return 25;
  if (ring === 'IB') return 50;
  return sector * (ring === 'D' ? 2 : ring === 'T' ? 3 : 1);
}
```

- [ ] **Step 3: Use it in `applyThrow`, and stop trusting `throw_` downstream**

At the top of `applyThrow`, replace:


```ts
export function applyThrow(state: X01State, throw_: Throw, settings: X01Settings): X01State {
  const currentPlayer = state.players[state.currentPlayerIndex];
  const trustedThrow: Throw = { ...throw_, points: computeDartPoints(throw_.sector, throw_.ring) };
  const newVisit = [...state.currentVisit, trustedThrow];
```

```ts
// app/api/matches/[id]/throws/route.ts
import { connectDB } from '@/lib/db';
import { Match, Visit } from '@/lib/db/models';
import { NextRequest, NextResponse } from 'next/server';
import mongoose from 'mongoose';
import { getIdentity } from '@/lib/identity';
import { canSubmitThrow, newlyCompletedVisit } from '@/lib/matchThrows';
import { publishMatchEvent } from '@/lib/realtime';
import { getGameModule, GameId } from '@/lib/games/registry';
import { createPlayerId, Throw, Ring } from '@/lib/types';

const VALID_RINGS: readonly Ring[] = ['S', 'D', 'T', 'OB', 'IB', 'M'];

/** Type guard for the six valid Ring values — basic request-shape hygiene, not anti-cheat (no
 *  engine trusts a client-supplied `points` value regardless of how well-formed the throw is). */
function isValidRing(ring: unknown): ring is Ring {
  return typeof ring === 'string' && (VALID_RINGS as readonly string[]).includes(ring);
}

/** Whether `sector` is legal for the given `ring`. OB/IB are fixed-value bull rings — the client
 *  encodes both with `sector: 25`, but the sector value doesn't affect them, so any sector is
 *  accepted. M (miss) is likewise sector-irrelevant. S/D/T require a sector in the 1-20 range. */
function isValidSector(sector: unknown, ring: Ring): boolean {
  if (typeof sector !== 'number' || !Number.isInteger(sector)) return false;
  if (ring === 'OB' || ring === 'IB' || ring === 'M') return true;
  return sector >= 1 && sector <= 20;
}

export async function POST(req: NextRequest, { params }: { params: Promise<{ id: string }> }) {
  const { id } = await params;
  if (!mongoose.Types.ObjectId.isValid(id)) {
    return NextResponse.json({ error: 'Invalid match id' }, { status: 400 });
  }

  let body: unknown;
  try {
    body = await req.json();
  } catch {
    return NextResponse.json({ error: 'Invalid JSON body' }, { status: 400 });
  }
  const throw_ = (body as { throw?: Throw })?.throw;
  if (!throw_ || typeof throw_.sector !== 'number' || typeof throw_.ring !== 'string') {
    return NextResponse.json({ error: 'Invalid throw' }, { status: 400 });
  }
  if (!isValidRing(throw_.ring)) {
    return NextResponse.json({ error: 'Invalid ring' }, { status: 400 });
  }
  if (!isValidSector(throw_.sector, throw_.ring)) {
    return NextResponse.json({ error: 'Invalid sector' }, { status: 400 });
  }

  await connectDB();
  const match = await Match.findById(id);
  if (!match) {
    return NextResponse.json({ error: 'Match not found' }, { status: 404 });
  }
  if (match.status !== 'live') {
    return NextResponse.json({ error: 'Match is not live' }, { status: 409 });
  }

  const { identity } = await getIdentity(req);
  const gameModule = await getGameModule(match.gameId as GameId);

  const check = canSubmitThrow(gameModule, match.state, identity.id);
  if (!check.ok) {
    return NextResponse.json({ error: check.error }, { status: check.status });
  }

  const playerId = createPlayerId(identity.id);
  // Points are never trusted from the client — every GameModule's applyThrow derives the real
  // score itself from sector+ring+its own state, so whatever points value throw_ carries here is
  // ignored by the engine entirely.
  const newState = gameModule.applyThrow(match.state, throw_, match.settings);

  const visit = newlyCompletedVisit(gameModule, newState, playerId);
  if (visit) {
    await Visit.create({ matchId: id, ...visit, enteredBy: identity.id });
  }

  match.state = newState;
  let status = match.status;
  if (gameModule.isComplete(newState)) {
    status = 'complete';
    match.status = 'complete';
    match.winnerId = gameModule.winner(newState);
    match.completedAt = new Date();
  }
  await match.save();

  await publishMatchEvent(id, { name: 'state', data: { state: newState, status, winnerId: match.winnerId } });

  return NextResponse.json({ ok: true });
}
```

```ts
// lib/games/cricket/engine.test.ts
import { describe, it, expect } from 'vitest';
import { init, applyThrow, undo, isComplete, winner, marksForThrow } from './engine';
import { createPlayerId } from '@/lib/types';
import { CricketDefaultSettings } from './schema';

const player1 = createPlayerId('p1');
const player2 = createPlayerId('p2');
const dart = (sector: number, ring: 'S' | 'D' | 'T' | 'OB' | 'IB' | 'M', order: 0 | 1 | 2 = 0) => ({
  sector: sector as any,
  ring,
  points: 0, // always ignored by applyThrow — never a meaningful input
  order,
});

describe('marksForThrow', () => {
  it('maps single/double/treble on a cricket number to 1/2/3 marks', () => {
    expect(marksForThrow(20, 'S')).toEqual({ number: 20, marks: 1 });
    expect(marksForThrow(20, 'D')).toEqual({ number: 20, marks: 2 });
    expect(marksForThrow(20, 'T')).toEqual({ number: 20, marks: 3 });
  });

  it('maps outer/inner bull to 1/2 marks on bull', () => {
    expect(marksForThrow(25, 'OB')).toEqual({ number: 'bull', marks: 1 });
    expect(marksForThrow(25, 'IB')).toEqual({ number: 'bull', marks: 2 });
  });

  it('returns null for non-cricket sectors and misses', () => {
    expect(marksForThrow(14, 'S')).toBe(null);
    expect(marksForThrow(1, 'T')).toBe(null);
    expect(marksForThrow(0, 'M')).toBe(null);
  });
});

describe('applyThrow: marks and closing', () => {
  it('a single hit on an open number applies 1 mark and scores nothing', () => {
    const state = init([player1, player2], CricketDefaultSettings);
    const after = applyThrow(state, dart(20, 'S'), CricketDefaultSettings);
    expect(after.marks[player1][20]).toBe(1);
    expect(after.points[player1]).toBe(0);
  });

  it('three single hits close a number with no overflow — no points scored', () => {
    let state = init([player1, player2], CricketDefaultSettings);
    state = applyThrow(state, dart(20, 'S', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(20, 'S', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(20, 'S', 2), CricketDefaultSettings);
    expect(state.marks[player1][20]).toBe(3);
    expect(state.points[player1]).toBe(0);
  });

  it('a treble on an open number closes it with 0 overflow — no points scored', () => {
    const state = init([player1, player2], CricketDefaultSettings);
    const after = applyThrow(state, dart(20, 'T'), CricketDefaultSettings);
    expect(after.marks[player1][20]).toBe(3);
    expect(after.points[player1]).toBe(0);
  });

  it('a treble on a number already at 2 marks closes it and scores the overflow', () => {
    let state = init([player1, player2], CricketDefaultSettings);
    state = applyThrow(state, dart(19, 'D'), CricketDefaultSettings); // 2 marks, still open
    // Closing needs only 1 more mark; the treble contributes 3, so 2 of them overflow.
    state = applyThrow(state, dart(19, 'T'), CricketDefaultSettings);
    expect(state.marks[player1][19]).toBe(3);
    expect(state.points[player1]).toBe(38); // 2 overflow marks * face value 19
  });

  it('hitting a number you have already closed scores full overflow while an opponent still has it open', () => {
    let state = init([player1, player2], CricketDefaultSettings);
    // player1's full visit: closes 18, then two harmless misses (a visit is always 3 darts)
    state = applyThrow(state, dart(18, 'T', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 2), CricketDefaultSettings); // visit ends, turn passes to player2
    // player2's full visit: does nothing relevant
    state = applyThrow(state, dart(1, 'M', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 2), CricketDefaultSettings); // visit ends, turn passes back to player1
    // player1 hits 18 again: already closed, player2 hasn't touched it, so both marks are pure overflow
    state = applyThrow(state, dart(18, 'D', 0), CricketDefaultSettings);
    expect(state.points[player1]).toBe(18 * 2);
  });

  it('scores nothing once every player has closed the number (it is dead)', () => {
    let state = init([player1, player2], CricketDefaultSettings);
    // player1's full visit: closes 17
    state = applyThrow(state, dart(17, 'T', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 2), CricketDefaultSettings); // visit ends, turn passes to player2
    // player2's full visit: closes 17 too, exactly (no overflow either way)
    state = applyThrow(state, dart(17, 'T', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 2), CricketDefaultSettings); // visit ends, turn passes back to player1
    // player1 hits 17 again: both players have now closed it — it's dead, scores nothing
    state = applyThrow(state, dart(17, 'D', 0), CricketDefaultSettings);
    expect(state.points[player1]).toBe(0);
  });

  it('outer bull scores overflow at face value 25, inner bull at 25 per mark', () => {
    let state = init([player1, player2], CricketDefaultSettings);
    // player1's visit 1: closes bull exactly via three outer bulls (0 overflow, 0 points)
    state = applyThrow(state, dart(25, 'OB', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(25, 'OB', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(25, 'OB', 2), CricketDefaultSettings);
    // player2's visit 1: passes
    state = applyThrow(state, dart(1, 'M', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 2), CricketDefaultSettings);
    // player1's visit 2: bull is already closed and player2 hasn't touched it, so both darts are
    // pure overflow — an outer bull (1 mark) scores 25, an inner bull (2 marks) scores 50
    state = applyThrow(state, dart(25, 'OB', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(25, 'IB', 1), CricketDefaultSettings);
    expect(state.marks[player1].bull).toBe(3);
    expect(state.points[player1]).toBe(75); // 25 + 50
  });

  it('a throw on a non-cricket sector or a miss applies no marks and scores nothing', () => {
    const state = init([player1, player2], CricketDefaultSettings);
    const after = applyThrow(state, dart(5, 'T'), CricketDefaultSettings);
    expect(after.points[player1]).toBe(0);
    expect(after.currentVisit).toHaveLength(1); // still a legal, recorded dart
  });

  it('ignores a forged points value — the real score is derived from sector+ring+state', () => {
    let state = init([player1, player2], CricketDefaultSettings);
    state = applyThrow(state, dart(16, 'T'), CricketDefaultSettings); // real score: 0 (closes, no overflow)
    const forged = { sector: 16 as const, ring: 'D' as const, points: 999, order: 1 as const };
    state = applyThrow(state, forged, CricketDefaultSettings); // 2 more marks, all overflow: 16*2
    expect(state.points[player1]).toBe(32);
  });
});

describe('leg and match completion', () => {
  it('closing all 7 numbers without a points lead does not end the leg', () => {
    let state = init([player1, player2], CricketDefaultSettings);
    // player1's visit 1: closes 20, 19, 18 with exact trebles (no overflow, no points)
    state = applyThrow(state, dart(20, 'T', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(19, 'T', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(18, 'T', 2), CricketDefaultSettings);
    // player2's visit 1: closes 17, then immediately overflows it for 34 points (player1 hasn't
    // touched 17 yet, so it's still open)
    state = applyThrow(state, dart(17, 'T', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(17, 'D', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 2), CricketDefaultSettings);
    expect(state.points[player2]).toBe(34); // 2 overflow marks * face value 17
    // player1's visit 2: closes 17 (already dead since player2 closed it — 0 points), then 16, 15
    state = applyThrow(state, dart(17, 'T', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(16, 'T', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(15, 'T', 2), CricketDefaultSettings);
    // player2's visit 2: passes
    state = applyThrow(state, dart(1, 'M', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 2), CricketDefaultSettings);
    // player1's visit 3: closes bull with 1 overflow (25 points) — closes all 7, but 25 < player2's
    // 34, so the leg does not end
    state = applyThrow(state, dart(25, 'OB', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(25, 'OB', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(25, 'IB', 2), CricketDefaultSettings);
    expect(state.points[player1]).toBe(25);
    expect(isComplete(state)).toBe(false);
  });

  it('closing all 7 numbers with a points lead ends the leg and increments legsWon', () => {
    let state = init([player1, player2], CricketDefaultSettings);
    state = applyThrow(state, dart(20, 'T', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(19, 'T', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(18, 'T', 2), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 2), CricketDefaultSettings);
    state = applyThrow(state, dart(17, 'T', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(16, 'T', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(15, 'T', 2), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(1, 'M', 2), CricketDefaultSettings);
    // player1 closes bull with exact outer-bull hits — no overflow anywhere, stays tied 0-0 with
    // player2, which is enough to win (the rule is "points >= every opponent", not "strictly more")
    state = applyThrow(state, dart(25, 'OB', 0), CricketDefaultSettings);
    state = applyThrow(state, dart(25, 'OB', 1), CricketDefaultSettings);
    state = applyThrow(state, dart(25, 'OB', 2), CricketDefaultSettings);
    expect(state.legsWon[player1]).toBe(1);
    expect(state.currentLegNumber).toBe(2);
    expect(state.points[player1]).toBe(0); // reset for the new leg
    expect(isComplete(state)).toBe(false); // firstTo is 3
  });

  it('winning the firstTo-th leg completes the match', () => {
    const settings = { firstTo: 1 };
    let state = init([player1, player2], settings);
    state = applyThrow(state, dart(20, 'T', 0), settings);
    state = applyThrow(state, dart(19, 'T', 1), settings);
```

```ts
// lib/games/cricket/engine.ts
import { Throw, PlayerId } from '@/lib/types';
import { CricketSettings } from './schema';

export type CricketNumber = 20 | 19 | 18 | 17 | 16 | 15 | 'bull';
export const CRICKET_NUMBERS: CricketNumber[] = [20, 19, 18, 17, 16, 15, 'bull'];
export type Marks = 0 | 1 | 2 | 3;

/** Maps a dart's sector+ring to the cricket number it hits and how many marks it's worth.
 *  Returns null for darts that don't affect cricket state at all (sectors 1-14, or a miss). */
export function marksForThrow(
  sector: number,
  ring: Throw['ring']
): { number: CricketNumber; marks: 1 | 2 | 3 } | null {
  if (ring === 'OB') return { number: 'bull', marks: 1 };
  if (ring === 'IB') return { number: 'bull', marks: 2 };
  if (ring === 'M') return null;
  if (sector < 15 || sector > 20) return null;
  const n = sector as CricketNumber;
  if (ring === 'S') return { number: n, marks: 1 };
  if (ring === 'D') return { number: n, marks: 2 };
  if (ring === 'T') return { number: n, marks: 3 };
  return null;
}

function faceValue(n: CricketNumber): number {
  return n === 'bull' ? 25 : n;
}

function emptyMarks(): Record<CricketNumber, Marks> {
  const m = {} as Record<CricketNumber, Marks>;
  CRICKET_NUMBERS.forEach((n) => (m[n] = 0));
  return m;
}

interface CricketVisitHistoryEntry {
  playerId: PlayerId;
  throws: Throw[];
  scoreBefore: number;
  scoreAfter: number;
  busted: boolean; // always false — Cricket has no bust concept, but the field is part of the
  // shared VisitHistoryEntry shape every GameModule's accessors expose.
  wasLegWin: boolean;
  wasMatchWin: boolean;
  marksBefore: Record<PlayerId, Record<CricketNumber, Marks>>;
  pointsBefore: Record<PlayerId, number>;
  legsWonBefore: Record<PlayerId, number>;
  legNumberBefore: number;
  matchCompleteBefore: boolean;
  winnerIdBefore: PlayerId | null;
}

export interface CricketState {
  players: PlayerId[];
  currentPlayerIndex: number;
  currentVisit: Throw[];
  marks: Record<PlayerId, Record<CricketNumber, Marks>>;
  points: Record<PlayerId, number>;
  legsWon: Record<PlayerId, number>;
  currentLegNumber: number;
  matchComplete: boolean;
  winnerId: PlayerId | null;
  visitHistory: CricketVisitHistoryEntry[];
}

export function init(players: PlayerId[], settings: CricketSettings): CricketState {
  const marks: Record<PlayerId, Record<CricketNumber, Marks>> = {};
  const points: Record<PlayerId, number> = {};
  const legsWon: Record<PlayerId, number> = {};
  players.forEach((p) => {
    marks[p] = emptyMarks();
    points[p] = 0;
    legsWon[p] = 0;
  });
  return {
    players,
    currentPlayerIndex: 0,
    currentVisit: [],
    marks,
    points,
    legsWon,
    currentLegNumber: 1,
    matchComplete: false,
    winnerId: null,
    visitHistory: [],
  };
}

export function applyThrow(state: CricketState, throw_: Throw, settings: CricketSettings): CricketState {
  const currentPlayer = state.players[state.currentPlayerIndex];
  const target = marksForThrow(throw_.sector, throw_.ring);

  // A dart's points are always derived here from sector+ring+state — never trusted from
  // throw_.points, which this function never reads.
  let dartPoints = 0;
  let marksAfterDart = state.marks;
  let pointsAfterDart = state.points;

  if (target) {
    const { number, marks: dartMarks } = target;
    const currentMarks = state.marks[currentPlayer][number];
    const applied = Math.min(dartMarks, 3 - currentMarks) as Marks;
    const overflow = dartMarks - applied;
    const newMarks = (currentMarks + applied) as Marks;

    const isClosedByThrower = newMarks === 3;
    const allOpponentsClosed = state.players
      .filter((p) => p !== currentPlayer)
      .every((p) => state.marks[p][number] === 3);
    dartPoints = isClosedByThrower && !allOpponentsClosed ? overflow * faceValue(number) : 0;

    marksAfterDart = { ...state.marks, [currentPlayer]: { ...state.marks[currentPlayer], [number]: newMarks } };
    pointsAfterDart = { ...state.points, [currentPlayer]: state.points[currentPlayer] + dartPoints };
  }

  const trustedThrow: Throw = { ...throw_, points: dartPoints };
  const newVisit = [...state.currentVisit, trustedThrow];

  const hasClosedAll = CRICKET_NUMBERS.every((n) => marksAfterDart[currentPlayer][n] === 3);
  const hasPointsLead = state.players
    .filter((p) => p !== currentPlayer)
    .every((p) => pointsAfterDart[currentPlayer] >= pointsAfterDart[p]);
  const isLegWin = hasClosedAll && hasPointsLead;

  if (isLegWin || newVisit.length === 3) {
    return endVisit(state, {
      currentPlayer,
      newVisit,
      scoreBefore: state.points[currentPlayer],
      scoreAfter: pointsAfterDart[currentPlayer],
      marksAfterDart,
      pointsAfterDart,
      isLegWin,
      settings,
    });
  }

  return { ...state, currentVisit: newVisit, marks: marksAfterDart, points: pointsAfterDart };
}

function endVisit(
  state: CricketState,
  args: {
    currentPlayer: PlayerId;
    newVisit: Throw[];
    scoreBefore: number;
    scoreAfter: number;
    marksAfterDart: Record<PlayerId, Record<CricketNumber, Marks>>;
    pointsAfterDart: Record<PlayerId, number>;
    isLegWin: boolean;
    settings: CricketSettings;
  }
): CricketState {
  const { currentPlayer, newVisit, scoreBefore, scoreAfter, marksAfterDart, pointsAfterDart, isLegWin, settings } =
    args;

  let legsWonAfter = state.legsWon;
  let currentLegNumberAfter = state.currentLegNumber;
  let matchCompleteAfter = state.matchComplete;
  let winnerIdAfter = state.winnerId;
  let marksNext = marksAfterDart;
  let pointsNext = pointsAfterDart;
  let wasMatchWin = false;
  let nextPlayerIndex = (state.currentPlayerIndex + 1) % state.players.length;

  if (isLegWin) {
    legsWonAfter = { ...state.legsWon, [currentPlayer]: state.legsWon[currentPlayer] + 1 };
    if (legsWonAfter[currentPlayer] >= settings.firstTo) {
      matchCompleteAfter = true;
      winnerIdAfter = currentPlayer;
      wasMatchWin = true;
      nextPlayerIndex = state.currentPlayerIndex; // match over, no next turn
    } else {
      currentLegNumberAfter = state.currentLegNumber + 1;
      const resetMarks: Record<PlayerId, Record<CricketNumber, Marks>> = {};
      const resetPoints: Record<PlayerId, number> = {};
      state.players.forEach((p) => {
        resetMarks[p] = emptyMarks();
        resetPoints[p] = 0;
      });
      marksNext = resetMarks;
      pointsNext = resetPoints;
    }
  }

  const historyEntry: CricketVisitHistoryEntry = {
    playerId: currentPlayer,
    throws: newVisit,
    scoreBefore,
    scoreAfter,
    busted: false,
    wasLegWin: isLegWin,
    wasMatchWin,
    marksBefore: state.marks,
    pointsBefore: state.points,
    legsWonBefore: state.legsWon,
    legNumberBefore: state.currentLegNumber,
    matchCompleteBefore: state.matchComplete,
    winnerIdBefore: state.winnerId,
  };

  return {
    ...state,
    marks: marksNext,
    points: pointsNext,
    legsWon: legsWonAfter,
    currentLegNumber: currentLegNumberAfter,
    matchComplete: matchCompleteAfter,
    winnerId: winnerIdAfter,
    currentVisit: [],
    currentPlayerIndex: matchCompleteAfter ? state.currentPlayerIndex : nextPlayerIndex,
    visitHistory: [...state.visitHistory, historyEntry],
  };
}

export function undo(state: CricketState): CricketState {
  if (state.visitHistory.length === 0) return state;
  const last = state.visitHistory[state.visitHistory.length - 1];
  const newHistory = state.visitHistory.slice(0, -1);
  return {
    ...state,
    marks: last.marksBefore,
    points: last.pointsBefore,
    legsWon: last.legsWonBefore,
    currentLegNumber: last.legNumberBefore,
    matchComplete: last.matchCompleteBefore,
    winnerId: last.winnerIdBefore,
    currentVisit: [],
    currentPlayerIndex: state.players.indexOf(last.playerId),
    visitHistory: newHistory,
  };
}

export function isComplete(state: CricketState): boolean {
  return state.matchComplete;
}

export function winner(state: CricketState): PlayerId | null {
  return state.winnerId;
}
```

```ts
// lib/games/cricket/stats.ts
import { Visit, StatTileDef, GameStats } from '@/lib/types';
import { CricketSettings } from './schema';
import { marksForThrow } from './engine';

export interface CricketStats extends GameStats {
  mpr: number;
  totalMarks: number;
  pointsScored: number;
  /** Numbers currently closed (0-7), live-only — a flat Visit[] log has no marks-progression
   *  state to replay this from, so computeStats always reports null here; matchStats (which
   *  reads live in-memory state) reports the real count. */
  numbersClosed: number | null;
}

export const EMPTY_CRICKET_STATS: CricketStats = {
  mpr: 0,
  totalMarks: 0,
  pointsScored: 0,
  numbersClosed: null,
};

export function computeStats(visits: Visit[], settings: CricketSettings): CricketStats {
  if (visits.length === 0) {
    return { ...EMPTY_CRICKET_STATS };
  }

  let totalMarks = 0;
  let totalDarts = 0;
  let pointsScored = 0;

  visits.forEach((visit) => {
    pointsScored += (visit.scoreAfter ?? 0) - (visit.scoreBefore ?? 0);
    visit.throws.forEach((t) => {
      totalDarts++;
      const target = marksForThrow(t.sector, t.ring);
      if (target) totalMarks += target.marks;
    });
  });

  const mpr = totalDarts > 0 ? (totalMarks / totalDarts) * 3 : 0;

  return {
    mpr: Math.round(mpr * 100) / 100,
    totalMarks,
    pointsScored,
    numbersClosed: null,
  };
}

export const statTiles: StatTileDef<CricketStats>[] = [
  { label: 'MPR', key: 'mpr', value: (s) => s.mpr.toFixed(2) },
  { label: 'Total Marks', key: 'totalMarks', value: (s) => `${s.totalMarks}` },
  { label: 'Points', key: 'pointsScored', value: (s) => `${s.pointsScored}` },
  {
    label: 'Numbers Closed',
    key: 'numbersClosed',
    value: (s) => (s.numbersClosed === null ? '—' : `${s.numbersClosed}/7`),
  },
];
```

```ts
// lib/games/cricket/index.ts
import { GameModule, PlayerId, Throw } from '@/lib/types';
import { CricketState, init as initEngine, applyThrow, undo, isComplete, winner } from './engine';
import { CricketSettings, CricketSettingsSchema, CricketDefaultSettings } from './schema';
import { computeStats, statTiles } from './stats';
import { matchStats } from './matchStats';
import { ScoreboardSlot } from './components';
import { Target } from 'lucide-react';

const players = (state: CricketState): PlayerId[] => state.players;

const currentPlayer = (state: CricketState): PlayerId => state.players[state.currentPlayerIndex];

const visitProgress = (state: CricketState): { darts: number; max: number; throws: Throw[] } => ({
  darts: state.currentVisit.length,
  max: 3,
  throws: state.currentVisit,
});

const matchInfo = (state: CricketState, settings: CricketSettings): { label: string; value: string }[] => [
  { label: 'Leg', value: String(state.currentLegNumber) },
];

const visitHistory = (
  state: CricketState,
  playerId: PlayerId
): { throws: Throw[]; scoreBefore: number; scoreAfter: number; busted: boolean }[] =>
  state.visitHistory
    .filter((entry) => entry.playerId === playerId && entry.legNumberBefore === state.currentLegNumber)
    .map((entry) => ({
      throws: entry.throws,
      scoreBefore: entry.scoreBefore,
      scoreAfter: entry.scoreAfter,
      busted: entry.busted,
    }))
    .reverse();

const heatmap = (state: CricketState, playerId: PlayerId): Record<string, number> => {
  const counts: Record<string, number> = {};
  state.visitHistory
    .filter((entry) => entry.playerId === playerId)
    .forEach((entry) => {
      entry.throws.forEach((t) => {
        const key = `${t.ring}${t.sector}`;
        counts[key] = (counts[key] ?? 0) + 1;
      });
    });
  return counts;
};

const lastCompletedVisit = (
  state: CricketState,
  playerId: PlayerId
): { throws: Throw[]; scoreBefore: number; scoreAfter: number; busted: boolean; isCheckout: boolean } | null => {
  const entries = state.visitHistory.filter((entry) => entry.playerId === playerId);
  if (entries.length === 0) return null;
  const latest = entries[entries.length - 1];
  return {
    throws: latest.throws,
    scoreBefore: latest.scoreBefore,
    scoreAfter: latest.scoreAfter,
    busted: latest.busted,
    isCheckout: latest.wasLegWin,
  };
};

const CricketModule: GameModule<CricketState, CricketSettings> = {
  id: 'cricket',
  name: 'Cricket',
  description: 'Close all numbers, score the most points',
  icon: Target,
  playerRange: [2, 4],
  status: 'stable',

  settingsSchema: CricketSettingsSchema,
  defaultSettings: CricketDefaultSettings,

  init: initEngine,
  applyThrow,
  undo,
  isComplete,
  winner,

  players,
  currentPlayer,
  visitProgress,
  matchInfo,
  visitHistory,
  heatmap,
  lastCompletedVisit,
  matchStats,

  ScoreboardSlot,
  primaryMetric: (state: CricketState, playerId: PlayerId) => ({
    label: 'Points',
    value: state.points[playerId].toString(),
  }),

  computeStats,
  statTiles,
};

export default CricketModule;
```
